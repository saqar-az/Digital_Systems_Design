# Digital Systems Design Course
This repository contains homework and projects for my Digital Systems Design course at university. Designs are implemented in VHDL and Verilog and simulated using ModelSim.

|  | Assignment | Description |
|---|------------|-------------|
| **HW1** | **4-bit Carry Skip Adder** | Implements a carry skip adder with 4 full adders and skip logic |
| **HW2** | **Transistor-Level Logic Gate** | Implements logic function |
| **HW3** | **Full Subtractor** | Implements a full subtractor |
| **HW4** | **4-to-1 Encoder** | Encodes 4 inputs into 2-bit binary output |
| **HW5** | **Shift Register** | Implements a shift register with left/right shift capability |
| **HW6** | **7×5 Array Multiplier** | Multiplies a 7-bit number by a 5-bit number using structural Verilog |
| **HW7** | **8-bit ALU** | Arithmetic Logic Unit with 12 operations and flag outputs |
